# AI Tools Used — ExpenseFlow

This document describes the AI tools used during the development of ExpenseFlow.

AI tools were used for planning, implementation support, testing, debugging, and documentation. All changes were reviewed and validated before integration.

---

## Tools Used

| Tool | Usage |
|------|-------|
| Google Antigravity | Codebase analysis, feature implementation, test generation, debugging support |
| Cursor | Code review, diff checking, and small fixes |
| ChatGPT | Architecture planning, prompt improvement, and documentation support |

---

## Google Antigravity

Used as the main AI development assistant.

Contributions:

- Analysed existing project structure and code flow
- Assisted in implementing expense validation rules
- Generated and reviewed test cases
- Helped analyse test failures
- Supported documentation creation

---

## Cursor

Used for code review and refinement.

Contributions:

- Reviewed AI-generated changes
- Inspected code differences
- Assisted with debugging and corrections

---

## ChatGPT

Used for planning and communication.

Contributions:

- Helped design application architecture
- Improved AI prompts
- Assisted with documentation structure
- Reviewed engineering decisions

## Responsible AI Usage


AI tools were used as development assistants.


Practices followed:


- Reviewed generated code before use
- Verified changes through automated tests
- Checked security and business rules
- Maintained ownership of final decisions


---
## Conclusion

AI tools helped improve development speed, testing workflow, and documentation quality while keeping human review and validation as an essential part of the process.
